# CareFlow Design System Overview

Based on the provided mock-up, the CareFlow application utilizes a clean, modern, and user-friendly design system.

## Overall Aesthetic
-   **Clean and Modern:** A minimalist approach with ample whitespace.
-   **Soft Shadows:** Subtle shadows are used to give depth to cards and elements, making them appear to float slightly above the background.
-   **Rounded Corners:** All major UI elements, including cards, buttons, and input fields, feature consistently rounded corners, contributing to a friendly and approachable feel.

## Color Palette
The primary colors observed are a calming combination of blues and an accent of pink.
-   **Primary Blue:** Used for headers, active states, and primary action buttons.
-   **Accent Pink:** Utilized for data visualization (e.g., the 'Systole' line on the blood pressure graph).
-   **Accent Light Blue/Teal:** Used for other data visualizations (e.g., the 'Diastole' line, oxygen level bars).
-   **Neutral Backgrounds:** White and very light grey are used for card backgrounds and the overall application background, ensuring content stands out.
-   **Typography Color:** Dark grey or black for primary text, ensuring high readability.

## Typography
A sans-serif font family is used throughout the application, prioritizing legibility and a modern feel.
-   **Hierarchy:** Font sizes and weights are varied to establish a clear visual hierarchy, with titles being larger and bolder, and supporting text being smaller.
    -   Example: "My Health" (large, bold) vs. "Blood Pressure" (medium, regular) vs. "12:48 AM" (small, light).

## Iconography
-   **Line-Art Icons:** Simple, recognizable line-art icons are consistently used across all metric displays and the navigation bar.
-   **Consistency:** Icons are monochromatic (or use a single accent color) and maintain a uniform style, enhancing visual coherence.

## UI Components

### Cards
-   **Structure:** Rectangular with significantly rounded corners and subtle drop shadows.
-   **Purpose:** Used to group related information, such as metric graphs, notifications, doctor contact details, and hospital information.

### Data Visualization
-   **Line Graphs:** Feature smooth lines, clear data points, and distinct colors for different metrics (e.g., Systole and Diastole). Legends are simple and easy to understand.
-   **Bar Graphs/Activity Trackers:** Represent progress or historical data (e.g., daily oxygen levels) using filled bars within a rounded container.

### Buttons
-   **Primary Buttons:** Solid colored (blue) with rounded corners and white text (e.g., "Get Direction").
-   **Secondary Buttons:** Outlined with colored text, maintaining rounded corners (e.g., "Call Hospital").

### Navigation Bar
-   **Bottom Tab Navigation:** Features clear icons and text labels for primary navigation points ("Dashboard", "My Health", "Care", "Browse"). The active tab is highlighted.

### Input Fields
-   **Search Bar:** A prominent, rounded input field with a search icon on the left and placeholder text, indicating its function.

## Layout and Spacing
-   **Whitespace:** Generous use of whitespace ensures elements are not cluttered, promoting a sense of calm and focus.
-   **Padding:** Consistent internal padding within cards and around UI elements for a balanced look.
-   **Grid Layout:** Metrics are arranged in a grid-like fashion, making them easy to scan and digest.

## Imagery
-   **Profile Pictures:** Small, circular profile images are used for personal identification (e.g., doctor, patient in urgent notification).
-   **Maps:** Integrated map views provide clear location information for urgent care scenarios.

This design system promotes a clear, intuitive, and aesthetically pleasing user experience for health monitoring.
