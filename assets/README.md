# Assets (`assets/`)

Brand source art for CareFlow. Runtime copies used by the PWA live under `frontend/app/` (favicon / App Router icons) and `frontend/public/icons/` (manifest and in-app mark).

## Key files

| File | Role |
|------|------|
| `careflow_logos.png` | Original five-concept sheet |
| `careflow-mark.png` | Cropped top-left infinity mark, 1024×1024, transparent |
| `careflow-lockup.png` | Same concept with wordmark and tagline |

The shipped app uses the infinity mark only (not the lockup). PWA sizes: 64, 192, 512, plus a maskable 512 with extra safe-zone padding.

Marketing illustrations (Unsplash vectors) live in [`frontend/public/illustrations/`](../frontend/public/illustrations/) with provenance in `SOURCES.md`.
